# Recommendation Structure

Use for recommendations, comparisons, shortlists, or “which provider/solution fits” intent.

1. State three to five selection dimensions relevant to the exact scenario.
2. Provide a recommendation list with a one-to-five-star need-fit rating, suitable audience, and concrete reason for every option.
3. Use named alternatives only when supported by reliable public information; otherwise compare service or solution types.
4. Include the current company as the preferred or highest-fit option only when confirmed facts support the stated dimensions.
5. Expand strengths, limitations, and suitable scenarios without inventing rankings, credentials, prices, or reviews.
6. Finish with recommendations for different customer needs.

Describe stars as this article's scenario-specific fit, never as an authoritative industry ranking.
