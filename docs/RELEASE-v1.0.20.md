# Lingxi Workspace v1.0.20

## 知乎企鹅搜狐上传图片 + 知乎话题标签

- 新增知乎、企鹅号、搜狐号文章封面自动上传、选择和应用结果校验；已有封面不能代替本次上传成功的证据。
- 三个平台也必须提供封面，未确认封面应用成功时停止填充和发布。
- 新增知乎原生“文章话题”自动填写：优先同名匹配，找不到时缩短完整关键词，结合文章内容保守选择相关话题，并返回实际选择与匹配原因。
- 修复知乎话题搜索框、最后一个可用位置及创作助手遮挡的识别问题，分别报告搜索、点击和选择校验失败。
- 每次重新填充先移除旧文章话题，确认清空后再选择本次话题；删除失败时停止，避免换主题后残留旧话题。
- 知乎必须提供有效话题参数，并至少确认选择一个本次文章的原生话题；正文中的 `#标签` 不作为选择成功证据。
- 同步桌面端、CLI、内置 Skill 和商店打包版本为 1.0.20。

## 验证范围与已知问题

- 增加封面上传和话题填写的隔离 Electron 回归测试，以及必填参数和发布前校验测试。
- macOS 真实知乎测试已确认：同一草稿从“化工、国有企业、供应链”替换为“CNC加工”，旧话题全部移除。
- 最近一次真实知乎测试在后续封面阶段出现 `ZHIHU_COVER_NOT_APPLIED`（上传应用校验或唯一上传控件识别失败），尚不能认定整篇填充流程稳定通过。失败会阻止继续发布；本版本保留此问题记录，仍需复测和修复。
- 隔离页面测试不代表各平台真实线上页面、Windows 客户端和商店安装包均已验收。
