# Lingxi Workspace v1.0.21

## 加入微信公众号+列举

- 新增微信公众号配置、文章排版及官方接口草稿保存，并读回核对结果；正式发表或群发仍需在公众号后台操作。
- 新增列举网配置和表单自动填充，支持正文及图片附件；填充完成后由用户完成验证码和提交。
- 使用指南新增小字提示：使用微信公众号或列举网前，请先进入「平台账号」中对应平台的「设置」，填写并保存相关配置。
- 加固头条号自动发布：兼容有广告确认弹窗和直接进入预览的流程，结合提示文案、按钮和实际可见状态识别弹窗，等待按钮就绪及弹窗关闭，避免重复点击最终发布。
- 诊断包增加头条发布过程中的识别方式、按钮状态和等待原因，便于定位页面差异；不导出网页 DOM 或账号凭据。
- 同步桌面端、CLI、内置 Skill 和商店版本为 1.0.21；Windows 商店包版本为 1.0.21.0。

## 验证范围

- 头条发布隔离浏览器测试覆盖有／无弹窗、非标准弹窗及按钮、延迟出现、按钮暂不可用、慢关闭、页面缩放、遮挡和重复提交保护。
- 安装包构建与验证结果以此分支对应提交的 GitHub Actions 记录为准。
- 隔离测试不代表用户真实账号页面已验收；微信公众号只存草稿，列举网只自动填充。
