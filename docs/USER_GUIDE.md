# GEO Publisher 使用指南

GEO Publisher 是客户内容与多平台分发工作台。桌面端管理客户项目、素材、文章和平台登录；WorkBuddy 负责理解需求、生成选题和文章，并通过桌面端执行填充或发布。

## 首次使用

1. 打开 GEO Publisher，在“客户项目”中创建一个项目。
2. 填写客户名称、公司资料、行业、产品和允许公开的案例。资料不完整时也可以先保存，之后继续补充。
3. 进入“平台账号”，只打开需要使用的平台并完成登录。
4. 点击左侧“连接 WorkBuddy”，将复制的指令粘贴给 WorkBuddy 并发送。
5. 在“内容中心”添加图片素材。可以让 WorkBuddy 整理待识别图片，整理完成后会保存分类、摘要和检索信息。
6. 让 WorkBuddy 生成选题和文章。文章保存后可以在内容中心预览。
7. 从文章进入“分发”，选择目标平台。建议先选择“仅填充”，确认页面内容无误后，再明确选择“真实发布”。

## 客户项目

客户项目是最重要的隔离边界。每个项目分别保存：

- 公司资料和内容偏好；
- 六个平台的登录状态；
- 图片素材、选题、文章和分发记录。

点击左侧顶部的“当前客户项目”可以切换项目，也可以在“客户项目”页面使用“切换”按钮。编辑其他项目资料不会自动切换当前项目。发布任务执行期间不能切换项目，避免内容或账号串用。

## 内容中心

- **素材**：上传产品、设备、案例、工厂或资质图片。图片会复制到当前项目目录，并按文件哈希去重。
- **选题**：普通选题使用后仍保留，但默认不再自动重复选择；常青主题可以继续生成新的角度变体。
- **文章**：保存结构化标题、摘要、段落、小标题、列表、引用和图片。点击“预览”检查最终结构。

## 分发方式

- **仅填充**：把文章写入平台编辑器，不点击发布，适合首次检查或页面变化后的验证。
- **真实发布**：在确认目标平台、标题、封面和声明后执行发布。每个平台独立处理，某个平台失败不会自动重发其他平台。
- **结果待确认**：先到平台管理页核对标题和状态，不要立即再次点击发布。

一次只选择需要发布的平台即可。百家号、头条号和网易号通常需要封面；平台页面实际要求以当前账号和页面提示为准。

## 搭配 WorkBuddy 的简易流程

第一次使用请按顺序完成。桌面端“使用指南”中提供了每一步的一键复制提示词。

### 1. 连接 WorkBuddy

点击桌面端左侧“连接 WorkBuddy”，把自动复制的连接指令粘贴到 WorkBuddy 并发送。连接成功后，WorkBuddy 才能读取当前客户项目。

### 2. 配置公司资料

把已有公司简介直接发给 WorkBuddy，让它提取公司名称、行业、产品或服务、优势、目标客户、案例和资质。WorkBuddy 最多追问两轮，并在得到“确认创建”或“确认写入”后保存，不能自动编造公司事实。

推荐提示词：

```text
请帮我配置 GEO Publisher 当前客户项目的公司资料。如果当前没有项目，请帮我新建一个；如果已经有项目，只更新当前项目。请从我提供的简介中提取并适度润色可公开资料，只追问最关键的缺失信息，最多两轮。整理后先给我确认，必须等我明确回复“确认创建”或“确认写入”后再保存。不要编造公司事实。

公司简介：
【把公司简介粘贴到这里】
```

### 3. 整理图片并生成内容

先在内容中心上传图片，再让 WorkBuddy 整理待整理素材。随后让它生成 7 天选题和第一篇文章，先保存到内容中心，不要直接发布。

### 4. 完成一次仅填充检查

让 WorkBuddy 把最新文章填充到一个平台，但明确说明“不要点击发布”。人工检查标题、正文、封面和声明。

### 5. 完成一次真实发布

确认填充页面无误后，再明确要求真实发布。发布后必须查询管理页并核对文章状态；结果不明确时禁止再次点击。

### 6. 最后开启自动化

在 WorkBuddy 中新建自动化任务并设置运行时间，把桌面端指南生成的自动化提示词作为任务说明。提示词会锁定当前客户项目，并要求：

- 六个平台串行执行；
- 不同平台分别生成文章；
- 发布前检查登录、内容和必填项；
- 发布后查询管理页对账；
- 登录、验证码、风控或次数用完时暂停并提醒；
- 结果不明确时只提醒人工核对，禁止自动重发；
- 同一文章不得重复发布。

不要在完成一次仅填充和一次真实发布之前开启自动发布。

## 状态处理

| 状态 | 应该怎么做 |
| --- | --- |
| 已填充 | 检查平台页面，确认无误后再决定是否发布。 |
| 发布成功 | 桌面端已完成发布后对账。 |
| 需要人工处理 | 按提示完成登录、验证码或风控操作，再回到桌面端重试。 |
| 今日次数已用完 | 当天停止该平台，不要连续重试。 |
| 结果待确认 | 去管理页核对，不要连续点击发布。 |

## 常见问题

### 只发一个平台可以吗？

可以。在分发页面只勾选目标平台即可。

### 换客户后账号会串吗？

不会。切换项目会同时切换对应的平台会话和内容库。任务执行时会锁定切换。

### 为什么内容没有立即发布？

如果选择的是“仅填充”，它只会写入编辑器，不会点击发布。真实发布需要明确确认。

### 平台提示权限或验证码怎么办？

在桌面端打开对应平台，完成平台要求的操作后再重试。不要通过连续点击绕过平台限制。

### 文章发布后还能切回工作台吗？

可以。平台页面顶部有“返回工作台”入口，返回不会删除登录状态或分发记录。

## 安全建议

- 不要在文章中填写平台密码、验证码或客户隐私信息。
- 不同客户建立不同项目，不要共用项目或平台账号。
- 真实发布前检查标题、封面、声明和目标平台。
- 结果不明确时先对账，避免重复发布。
